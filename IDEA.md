# LMPI — LLM Prompt-Injection Firewall

## Что это

**LMPI** (LLM Prompt-Injection Firewall) — прозрачный прокси, который защищает LLM-приложения от prompt injection и утечки system prompt. Drop-in замена `base_url` — приложение продолжает работать через OpenAI-совместимый API, но каждый входящий prompt проходит через трёхуровневую проверку.

## Проблема

Современные LLM-приложения уязвимы к атакам через пользовательский ввод:

- **Prompt injection** — атакующий заставляет модель игнорировать system prompt и выполнять произвольные инструкции
- **System prompt leakage** — извлечение конфиденциального system prompt через специально сконструированные запросы
- **Jailbreak** — обход safety-ограничений модели через ролевые игры, кодировку, многоязычные трюки

Существующие решения либо vendor-lock (Azure AI Content Safety, AWS Guardrails), либо слишком сложные для интеграции, либо не имеют воспроизводимых метрик.

## Решение

LMPI — lightweight прокси с тремя уровнями защиты:

1. **Ingress Normalization** — детерминированная очистка входного потока (NFKC, zero-width chars, base64/hex/rot13 decode, нейтрализация псевдо-системных разделителей)
2. **Fast Path** — regex/heuristic паттерны на известные jailbreak-конструкции с минимизацией false positives
3. **Deep Path** — ML-классификатор (DeBERTa через ONNX Runtime) для сложных случаев

Плюс **Canary Token Detection** — HMAC-токены в system prompt для обнаружения утечки.

## Позиционирование

**НЕ** "Zero Trust AI Proxy с DLP и tool firewall" — это распыляет фокус.

**ДА** — конкретный, сфокусированный инструмент: LLM Prompt-Injection Firewall с честными метриками и воспроизводимым бенчмарком.

Ценность v1 — в инженерии и измерениях, не в количестве фич.

## Целевая аудитория

- Разработчики LLM-приложений, которым нужен быстрый security-слой без vendor-lock
- Инженеры по безопасности, оценивающие AI-risk
- Наниматели, рассматривающие портфолио — воспроизводимый бенчмарк = серьёзный сигнал

## Философия

- **Измеримо** — каждая claim подтверждается бенчмарком на frozen eval set
- **Прозрачно** — честно написано, что работает, а что нет
- **Воспроизводимо** — любой может прогнать бенчмарк и получить те же цифры
- **MVP-first** — маленький, но завершённый и измеренный проект лучше большого, но недоделанного
